# Random Forest Visualizer

Interaktive Browser-Lernapp für **Random Forests** und das Ensemble-Prinzip.

## Inhalte

- Random Forest als Ensemble aus vielen Entscheidungsbäumen verstehen
- Bootstrap-Sampling vereinfacht nachvollziehen
- Anzahl der Bäume verändern
- Baumtiefe und Rauschen verändern
- Mehrheitsentscheidung visuell sehen
- Trainings-Accuracy beobachten
- Durchschnittliche Blattanzahl und Baumtiefe sehen
- Stimmen einzelner Bäume vergleichen
- Eigene Punkte klassifizieren
- Hell-/Dunkelmodus
- Kein Quiz
- Keine Installation nötig

## Start

Einfach `index.html` öffnen oder über GitHub Pages bereitstellen.

## GitHub Pages

Repository → **Settings** → **Pages** → **Deploy from a branch** → `main` → `/ (root)` → **Save**

Danach ist die App typischerweise unter

`https://uisy.github.io/random-forest-visualizer/`

erreichbar.
